# 2026-11-11 Elice dev 30% 실험 원본

이 디렉터리는 기존 로컬 실행 증거의 복사본입니다. 게시 과정에서 API를 호출하지 않았습니다.

- `runs/`: 최초 실행과 continuation-1, recovery-2/3/4의 원본 390개 파일. 원본 응답 123개, 계획·승인·원장·사례 결과·최종 분석 포함.
- `claims/`: 5개 캠페인 일회성 승인 사용 기록을 원래 live 경로와 분리하여 보관한 감사 증거.
- `source-history/`: 실행 시점별 코드 해시를 복구하는 데 필요한 13개 원본 소스 스냅샷, 현재 코드와의 대응, 외부 DEVON 해시 기준.
- `analysis-source/`: 최종 분석에 쓰인 당시 스크립트. 로컬 절대 경로가 들어 있는 역사적 소스이며, 게시 검증용 CLI는 저장소 `tools/verify_published_archive.py`.
- `publication-provenance.json`: 원본 복사 경로, 게시 경로, SHA-256, 크기.

원본 JSON·Markdown의 Windows 경로는 그대로 보존합니다. `/model-lab/runs/` 이후의 상대 경로를 이 디렉터리 `runs/` 아래에 붙이면 게시 파일을 찾을 수 있습니다. 사용자에게 읽기 쉬운 경로·표·질문별 원문은 [상세 보고서](../../../docs/experiment/RESULTS.md)와 [사례집](../../../docs/experiment/CASEBOOK.md)에 있습니다.

총비용은 미확인입니다. 기록된 단가 기준 소계 $1.209497700–$1.267645900과 미확인 5시도의 예약 보류액 $0.40724675를 구분합니다. 합계 $1.674892650은 청구액이 아니라 보수적 예산 노출액입니다. 정답·검수는 모두 `unreviewed`이며 품질 평가는 초안 정답과 비교한 진단입니다.
