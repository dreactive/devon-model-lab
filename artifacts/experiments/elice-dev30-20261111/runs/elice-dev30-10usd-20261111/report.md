# Elice 6개 모델 실험: 첫 요청 후 중단

동일한 16개 dev 세트(A 11건 + B 5개 면접)를 6개 모델에 한 번씩 실행하도록 준비했다. 전체 예산은 **$10**, HTTP 시도 상한은 **192회**다. 사례·정답 검수 상태는 `unreviewed`다.

**실제 실행은 첫 GPT-6.1 Sol 요청의 HTTP 404와 사용량 누락으로 중단됐다. 완료 사례는 0건이며, 1건이 중단되고 나머지 95개 모델·사례 조합은 실행하지 않았다.** 이는 엔드포인트 통합 오류이며 모델의 답변 품질 실패로 집계하지 않는다.

|---|---|---|---|---|---|---|

실제 총비용과 남은 예산은 **미확인**이다. 토큰이 없는 시도 1건(사례 1건)을 0달러로 대체하지 않았다. 장부의 확인된 예산 차감 부분합 `0`은 실제 총비용 $0을 뜻하지 않는다. 첫 요청 전 보수적으로 예약한 금액은 $0.09659였고, 사용량 미확인 후 전체 예산을 잠갔다.

인터뷰당 평균 비용, 정답 일치 1건당 비용은 완료 결과가 없어 산출할 수 없다. 재시도는 0회이며, 실패 요청에 쓴 비용 비율도 사용량·과금이 미확인이므로 산출하지 않는다. 합격 임계값은 만들지 않았다.

## 구현·검증 상태

- 실제 호출 경로에서 매 HTTP 시도 전 작업별 예산과 전체 $10 예산을 함께 예약한다. 실패·재시도를 포함해 사용량을 정산하고, 캐시 요율이 모호하면 상한으로 예산을 차감하며 정확한 비용과 구분한다.
- 단가·예산·유효 승인이 없거나 사용량을 확인할 수 없으면 실행을 차단한다. 이번 중단 후 추가 요청은 없었고 기존 장부·캠페인 잠금은 보존했다.
- 첫 실행 전 전체 오프라인 테스트는 210개 통과·Windows 권한 관련 1개 건너뜀이었다. 후속 경로 검증 및 실제 호출 경로의 가짜 전송 테스트는 14개 모두 통과했다. Elice의 실제 성공 응답 정산은 아직 검증하지 못했다.
- DEVON의 추적 파일 1,265개, git 상태, 바이트코드 디렉터리가 전후 동일했다. 보호 대상 사례·정답·검수 파일 167개도 동일했다. 생성 결과에서 실제 API 키 문자열은 발견되지 않았다.

## 경로 수정과 재개 조건

설정된 6개 Elice 모델별 BASE_URL에 `/v1`이 빠져 있었다. API 키와 다른 설정을 보존하면서 `/v1`을 보완했고, 같은 경로 오류를 API 호출 전에 차단하는 검증을 추가했다. 이 경로는 [Elice 공식 Responses 예제](https://elice.io/en/ax/model-library/5e587c47-ee4a-4a03-9782-9d603d932abc)의 형식과 일치한다. 이 누락이 HTTP 404의 원인이라는 판단은 요청 경로와 공식 예제에 근거한 추론이며, 수정 후 실제 요청은 하지 않았다.

Elice 콘솔은 로그인 화면으로 연결되어 첫 요청의 청구 여부를 확인하지 못했다. **첫 요청의 사용량·청구 금액을 공급자 기록으로 확인하고 기존 장부에 반영해야 재개할 수 있다.** 현재 자동 재개 기능은 없다. 수정 전 계획과 승인에 기록된 엔드포인트·코드 지문은 이력으로 보존했다.

`ledger.json`의 `transport_integration=requires_transport_binding`은 CostBudget의 오래된 설명 필드다. 실제 호출에는 로컬·전체 예산을 함께 보호하는 EliceTransport가 연결됐으며, 예약·정산 이벤트와 관련 테스트가 이를 확인한다. 원본 장부는 수정하지 않았다.

## 근거 파일

- `ledger.json`, `campaign-result.json`: 시도·예산 중단 상태와 대기 작업.
- `results/gpt-6.1-sol-1.json` 및 관련 감사 기록: 첫 실행의 부분 기록. 첫 404 오류의 원문 응답 본문은 보존되지 않았다.
- `analysis.json`: 순차 실행 계획으로 첫 중단 사례를 추론한 표시와 미실행 사례. 완료된 모델 출력은 없다.
- `endpoint-repair.json`: 비밀값을 제외한 6개 설정 수정 내역.
- `integrity-and-status.json`, `devon-before.json`(상위 통합 검증 디렉터리), `devon-final.json`: 무변경 및 현재 상태 근거.
