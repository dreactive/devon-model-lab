## 비용과 보호 한도

- 실제 HTTP 요청: **125회 / 상한 192회**. 사용량이 있는 120회와 미확인 5회를 모두 연결했다.
- 실제 총비용: **미확인**. 미확인 요청을 0달러로 처리하지 않았으며, 해당 사례 4개를 별도로 표시했다.
- 제공 단가로 계산한 사용량 확인분: **$1.209497700–$1.267645900**. 캐시 단가·TTL 내역이 불확실한 부분은 범위를 유지했다.
- 미확인 5회에 대한 사전 예약 상한 합계: **$0.40724675**.
- 확인분 상한과 모든 미확인 예약을 합친 보수적 노출액: **$1.674892650 / $10**. 이는 실제 청구액이 아니다. 마지막 거절 후 실행은 잠겨 있고 새 호출은 없다.
- 확인 토큰 부분합: 입력 **1,015,304**, 출력 **91,313**. 5회가 누락되어 전체 토큰 합계는 미확인이다. 추론 토큰을 출력 토큰에 다시 더하지 않았다.

## 관측한 한계

- Flash의 질문 생성 8건은 추론을 포함한 2,000토큰 상한에서 잘렸다. Luna에서도 잘림 2회가 관측됐다.
- Haiku는 출력 종료 후 스키마·서비스 계약 검증 실패가 관측됐다. 입력·프롬프트·스키마를 고쳐 통과시키지 않았다.
- Argon 마지막 A 사례는 요청 취소로 남겼다. 30초 제한이 설정되어 있었지만 기록만으로 취소 원인을 확정하지 않았다. 해당 지연은 만들어 넣지 않았다.
- Sonnet은 `response_format`을 지원하지 않는다는 HTTP 400을 반환했다. 강제 도구 선택을 받지 않아 구조화 출력도 사용할 수 없다는 제공자 설명을 원문에 보존했다. 다른 15건을 같은 거절로 반복 호출하지 않았다.
- GPT는 Responses, Gemini·Claude는 같은 strict JSON 스키마를 전달하는 Chat 브리지를 사용했다. 출력 상한은 모두 2,000이며 기본 추론 설정은 바꾸지 않았다. 프로토콜 차이와 상한은 비교 조건이다.
- 실패 A 행의 `0ms` 초기값은 실측값으로 사용하지 않고 기록된 SDK 시도 지연의 합계를 사용했다. 원본 결과는 수정하지 않았다.
- 실행 후 Haiku의 top-level `cache_write_tokens` 별칭을 파서에 추가했고 71개 오프라인 테스트가 통과했다. 이 실행의 넓은 비용 범위와 예산 차감은 원래대로 보존했다.

**이 결과만으로 서비스 모델 교체를 권고할 근거는 부족하다.** 합성 dev 16개, 단일 실행, 미검수 정답·루브릭, A 의미 평가 미실행, 토큰·호환성 제한의 영향을 받는다. 모델 순위와 합격 임계값은 만들지 않았다.
